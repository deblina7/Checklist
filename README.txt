MY DAILY CHECKLIST

Files:
- index.html: checklist webpage
- manifest.json: home-screen app settings
- icon.svg: app icon
- sw.js: offline cache support

Features:
- Eight starter categories, including All at Once
- Add tasks under any category
- Add, rename, and delete categories
- Tick tasks, reset checkmarks daily, and save changes in browser storage
- Offline support after first load when hosted on HTTPS

IMPORTANT:
For a reliable home-screen app icon, upload these four files to an HTTPS static host (for example GitHub Pages), then open the HTTPS webpage in Chrome on Android and tap ⋮ > Add to Home screen (or Install app, if shown).

Opening index.html directly from a file manager may let you use the checklist, but Android/Chrome may not offer an installable home-screen shortcut and local file storage can vary.

Your tasks are saved in browser storage on that device. Avoid clearing the site's data if you want to keep them.
